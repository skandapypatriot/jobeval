# Milestone verification records

Each milestone report in this directory records what was actually implemented and verified. Reports distinguish:

- **completed:** backed by source code and an automated or manual check;
- **limited:** a safe fallback is available and the limitation is visible;
- **not verified:** the environment did not support the check;
- **not implemented:** the capability is outside the milestone's verified scope.

Reports never use design mockups as application screenshots. Captured images are named with the milestone and date and identify the build/backend state used.

The current verified status is summarized in the root `CHANGELOG.md` and `README.md`.
